# Experiment sources

These files retain the source hashes recorded with the results. Use
[`reproduce_extensions.py`](../reproduce_extensions.py) from the repository root
to restore their original layout in a new workspace and run the comparisons.
They are not standalone commands in this directory.

For individual analyses and the weaker-prior ablation, use the submitted
revision and its [manual instructions](https://github.com/GioiaZheng/paiec-2026/blob/d2d3e3c1e803880f4918f2f8065616b513731a40/REPRODUCIBILITY.md).
